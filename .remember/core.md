# Core — semantic invariant проекта

> Этот файл — инвариант проекта (semantic memory). Коммитится в git.
> Здесь живёт то, что **не меняется** от сессии к сессии: цель и семантический контекст.
> `now.md` и `today.md` — сессионные, gitignored.
> Нормативный поведенческий контракт агента находится только в [`AGENTS.md`](../AGENTS.md).

## Цель проекта

**Скаутинг CS2 для команды «Ушибу ногами».** Публичная статистика пяти составов → решения по вето,
тренировкам и планам на матчи осени 2026. Каждый вывод прослеживается до цифры в источнике.

## Контекст

- Стейкхолдер: капитан/аналитик команды «Ушибу ногами»; потребитель выводов — состав из шести игроков.
- Слои `00–05` — собственный контент проекта; `06_outputs/mcp-catalog/` — внешний корпус
  (зеркало каталога MCP), особый слой вне пирамиды evidence→synthesis (см. `AGENTS.md` § External corpus).
- Единственный источник данных на 2026-08-29 — снимок stats.whoajor.com. Демо, позиции игроков
  и пер-раундовые данные недоступны.
- Полностью локально после первичной загрузки модели (~120 MB ONNX при первом `kb:index`).

## Память сессии

- `.remember/now.md` — текущий фокус и незавершённая работа.
- `.remember/today.md` — краткий журнал сессии.
- `.remember/preferences.md` — динамические предпочтения формы ответа.

Эти файлы не переопределяют правила из `AGENTS.md`.

## Карта слоёв

- `00_context/` — immutable контекст (что за продукт, кто стейкхолдеры)
- `01_raw/` — сырые артефакты (raw evidence, immutable)
- `02_sources/` — короткие summary артефактов
- `03_wiki/` — концепты, агрегированные из источников
- `04_synthesis/` — интерпретация, гипотезы, open questions
- `05_decisions/` — принятые решения с rationale
- `06_outputs/` — финальные артефакты для людей + external corpus (зеркала библиотек)
